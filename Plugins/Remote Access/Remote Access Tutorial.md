# Remote Access

I no longer recommend OctoEverywhere due to reliability issues and aggressive paywalling.

Join the [Discord](https://discord.gg/aZGUk69Mp) for current recommendations and setup help.

## Alternatives

**Tailscale** — creates a private VPN between your devices. Once installed on your printer and phone/computer, you can access the Moonraker web UI and send prints remotely as if you were on the local network. No port forwarding required.

**Obico** — a self-hostable (or cloud-hosted) remote access and AI failure detection platform. Works with Klipper/Moonraker. Good option if you want failure detection alongside remote access.

Full guides for these are in progress. Check the Discord for the latest setup instructions from the community.
