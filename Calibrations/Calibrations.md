# Fan timing
By defualt, fan speed up time and kick start time are somewhat bad. I found after running the script my overhangs became much better as the fan would start when it was supposed to.
> How to run
1. Download [this](https://github.com/Camden-Winder/Qidi-Q2-superuser/blob/main/Calibrations/fan_test.py) python script to your computer. You will need to edit the IP adress to be your own printer's
2. Run the test with `py fan_test.py` and then let it do its thing
