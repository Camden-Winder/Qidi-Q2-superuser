# Remote Access

Remote access lets you monitor and control your printer from outside your home network.

---

## Current status

OctoEverywhere was previously recommended here, but reliability issues and aggressive paywalling make it hard to suggest.

A Tailscale-based remote access guide is in progress. Check the [Discord](https://discord.gg/aZGUk69Mp) for current status before that guide is published.

---

## Working alternative: Obico

Obico (formerly The Spaghetti Detective) is a self-hostable remote access and monitoring tool that works with Klipper and Moonraker.

It supports:
- Remote monitoring with webcam stream
- Print failure detection
- Mobile and web access

See the [Obico Klipper setup guide](https://www.obico.io/docs/user-guides/klipper-setup/) for installation instructions.
