# Printables

Recommended prints for the Qidi Q2. All prints below are designed for the Q2 unless noted.

---

## Purge Bin

A small, simple purge bin that fits cleanly in the chamber. Useful for multi-color prints.

- [Purge Bin](https://www.printables.com/model/1390449-qidi-q2-poop-chutebucket/files)

---

## Riser

Fits three sides on a single plate — run it overnight. The tabs can be printed in a contrasting color.

**This is the only print that uses different slicer settings.** See the [Riser Settings](https://github.com/Camden-Winder/Qidi-Q2-superuser/blob/main/Printables/Riser%20Settings.txt) file for the specific values.

- [Riser](https://www.printables.com/model/1443536-qidi-q2-riser)

---

## Better Handle

The stock Qidi handle isn't great. This replacement uses the factory screws.

Enable adaptive layer height for this print.

- [Door Handle](https://www.printables.com/model/1647312-yet-another-qidi-q2-door-handle)

---

## Screen Cover

Matches a black-and-white theme. No functional purpose.

- [Screen Cover](https://www.thingiverse.com/thing:7329016)

---

## Cardboard Spool Adapters

Helps cardboard spools run smoother inside the enclosure.

- [Spool Adapters](https://makerworld.com/en/models/988003-universal-cardboard-spool-adapter-ring?from=search#profileId-963058)

---

## Filament Clip

Good for holding filament rolls closed during storage or when drying in the box. Print in PETG, scale up by 5%, use 0.16 mm layer height.

- [Filament Clip](https://makerworld.com/en/models/1303141-clip-mate-filament-clip?from=search#profileId-1335869)

---

## TPU Bypass Top Spool Holder

For BunnyBox users printing TPU or other flexibles via the bypass gate. Routes filament from the top of the printer to reduce tight bends that cause jams. Fits risers.

- [Q2 Flexibles Top Spool Holder – The Mi3 Channel](https://odysee.com/@The_Mi3_Channel:f/Q2-Flexibles-Top-Spool-Holder:a)
