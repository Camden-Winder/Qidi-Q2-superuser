All HH (Happy Hare / BunnyBox) and No-HH configurations have been made with all slicer changes required. Download the set that matches your setup and import them to OrcaSlicer.

- **HH** = you have BunnyBox / Happy Hare installed
- **No-HH** = stock printer or Just Faster (no BunnyBox)

If you need help understanding how to import, follow [this guide](https://www.obico.io/blog/orcaslicer-comprehensive-profile-management-guide/#using-orcaslicers-built-in-exportimport-functions)
