All Box/Boxless and nozzle configurations have been made with all slicer changes required for Bunny Box. Download the ones that match your setup and import them into Orca.

If you need help importing, follow [this guide](https://www.obico.io/blog/orcaslicer-comprehensive-profile-management-guide/#using-orcaslicers-built-in-exportimport-functions)

**Not sure which to pick?** If you have the Qidi Box attached, use a **Box** preset. If you're running the printer without the box (or bypassing it), use a **Boxless** preset. See the [Bypass FAQ](https://github.com/Camden-Winder/Qidi-Q2-superuser/blob/main/Install-Script/FAQ-BunnyBox%26Helixscreen.md) for details on using bypass mode.

**New to this?** Start with the **0.4mm** preset — that's the default nozzle size the Q2 ships with.
